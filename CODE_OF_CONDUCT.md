# Code of Conduct

This project adopts the [Contributor Covenant v2.1][covenant], the most
widely-used open-source community standard. The canonical text lives at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Behavior standards and enforcement guidelines follow that document.

## Reporting

To report unacceptable behavior, email **conduct@placetopay.com**. All reports
are handled privately. For security vulnerabilities, use the dedicated channel
in [SECURITY.md](../SECURITY.md) instead.

## Scope

This code applies to all project spaces — issue trackers, pull requests,
discussions, and any other channel officially associated with this SDK.
